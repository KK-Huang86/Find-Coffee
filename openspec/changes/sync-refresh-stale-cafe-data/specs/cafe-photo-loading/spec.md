## ADDED Requirements

### Requirement: 照片識別碼被拒絕時同步更新並重試一次
即時解析照片時，若外部圖片來源回應 400 或 403，系統 SHALL 在同一次請求內同步更新該店資料以取得新的照片識別碼，並以新識別碼重新解析一次；重試後仍失敗則顯示預設圖片。背景照片快取 SHALL 只觸發一次。

#### Scenario: 識別碼過期，更新後解析成功
- **WHEN** 外部圖片來源對舊識別碼回應 400 或 403，且更新後取得不同的新識別碼
- **THEN** 系統以新識別碼解析並顯示實際照片

#### Scenario: 更新後識別碼未改變
- **WHEN** 外部圖片來源回應 400 或 403，但更新後的識別碼與原本相同
- **THEN** 系統不重試解析，記錄警告並顯示預設圖片

#### Scenario: 同一店家剛更新過
- **WHEN** 外部圖片來源回應 400 或 403，但該店在 600 秒內已更新過
- **THEN** 系統不再更新、不重試解析，顯示預設圖片

#### Scenario: 其他失敗不觸發更新
- **WHEN** 外部圖片來源回應 400、403 以外的非 200 狀態，或請求逾時
- **THEN** 系統不更新店家資料，顯示預設圖片

#### Scenario: 背景快取只觸發一次
- **WHEN** 照片解析觸發了同步更新與重試
- **THEN** 該次請求只送出一次背景照片快取任務
