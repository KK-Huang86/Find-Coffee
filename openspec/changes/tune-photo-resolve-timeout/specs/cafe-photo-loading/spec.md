## ADDED Requirements

### Requirement: 照片即時解析失敗需留下可追查紀錄
系統向外部圖片來源即時解析照片時，SHALL 分開限制建立連線與讀取回應的等待時間；外部來源回應非成功狀態時，系統 SHALL 記錄包含狀態碼與照片識別碼的警告紀錄，且紀錄內容 MUST NOT 包含 API 金鑰。

#### Scenario: 外部來源回應非成功狀態
- **WHEN** 系統即時解析照片，外部圖片來源回應非 200 的狀態碼
- **THEN** 系統顯示預設圖片，並記錄一筆包含該狀態碼與照片識別碼的警告

#### Scenario: 警告紀錄不洩漏金鑰
- **WHEN** 系統因外部來源回應非成功狀態而記錄警告
- **THEN** 警告內容不包含 API 金鑰

#### Scenario: 解析成功不記錄警告
- **WHEN** 外部圖片來源回應 200
- **THEN** 系統顯示實際照片，且不記錄警告

#### Scenario: 連線與讀取分開限時
- **WHEN** 系統向外部圖片來源發出解析請求
- **THEN** 建立連線最多等待 2 秒，讀取回應最多等待 4 秒
